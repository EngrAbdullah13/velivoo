# Environment and infrastructure

Audit: 2026-09-03. Values of credentials, tokens, passwords, signing secrets and account references are deliberately omitted. Presence is not validity. No IAM, SES sandbox, DNS ownership, SNS subscription or CloudFront resource was changed or independently verified live.

## Configuration behavior

packages/config/src/env.ts loads .env.local before .env but never overwrites an existing process value. Root npm scripts also use node --env-file=.env, so already populated values win. Frontend dev-server.mjs and Next have their own env-loading context. Restart/rebuild the appropriate process after changes; NEXT_PUBLIC values are browser-visible.

Current root flags: NODE_ENV=development; runtime=proof; provider=ses; real send, SES setup, tenant mapping and Route53 enabled; delivery queue disabled; import/Phase3 queue flags absent; platform tracking; local/dev authentication enabled. Therefore proof runtime is **not** safe evidence that an action cannot affect AWS.

Local DB is PostgreSQL on localhost5432; Redis localhost6379; frontend3000; gateway4000; public4001; gateway children4101–4104. Object files use local filesystem storage. Public base is the supplied HTTPS ngrok origin while frontend API URL remains localhost4000. The tunnel must route to4001 for SNS/click/unsubscribe.
